# Portfolio – Yuanyuan Zhang

Statische Portfolio-Seite ohne Build-Schritt (HTML, CSS, JS).

## Vor dem Veröffentlichen ersetzen

Die E-Mail-Adresse ist bereits eingetragen. Suche in `index.html` nach `data-todo` für die restlichen Platzhalter:

- LinkedIn-Profil
- GitHub-Profil
- Link zum NordHome-Repository

Prüfe außerdem die Zahlen und Formulierungen in den Projekten, ob sie zum aktuellen Stand passen.

## Auf GitHub Pages veröffentlichen

1. Neues Repository anlegen, z. B. `portfolio` (oder `DEIN-NAME.github.io` für die Hauptadresse).
2. Die Dateien `index.html`, `style.css` und `script.js` ins Repository legen und pushen.
3. Im Repository unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/ (root)` wählen.
4. Nach ein bis zwei Minuten ist die Seite unter `https://DEIN-NAME.github.io/portfolio/` erreichbar.

## Lokal ansehen

`index.html` im Browser öffnen, oder in VS Code mit der Erweiterung „Live Server“.
