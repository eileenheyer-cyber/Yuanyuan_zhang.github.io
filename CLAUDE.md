# Portfolio website (GitHub Pages, static HTML/CSS/JS, no build)

- Branch `main` is the live site. After finishing a change, commit and `git push origin HEAD`.
- Statistics blog posts: **read `BLOG_STYLE_GUIDE.md` first** and follow it for every new or edited post (layout, components, stakeholder section, diagrams, cover image, Statistics card, checklist).
- Reuse the CSS variables and components in `style.css`; no frameworks. When `style.css` changes, bump the `?v=` cache-buster on the pages that link it.
- Write the blog in English.
